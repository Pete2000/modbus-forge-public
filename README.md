# Modbus Forge

面向 Windows 现场调试的 Modbus 通信工作台，覆盖 **Modbus TCP 客户端/服务器** 与 **Modbus RTU 主站/从站**。

基于 Electron、React 和 TypeScript 开发。

- 现场安装与安全操作：[docs/现场使用指南.md](docs/现场使用指南.md)

## 已实现能力

- TCP 客户端与 RTU 主站传输；请求按连接串行排队。
- TCP 服务器监听与 RTU 从站监听可同时运行；TCP 默认仅绑定 `127.0.0.1:5020`。
- 功能码 `01`、`02`、`03`、`04`、`05`、`06`、`0F`、`10`。
- 每个 Unit ID 均有独立的线圈、离散输入、保持寄存器、输入寄存器数据区；可在界面直接编辑，外部写入会立即同步到可写数据区。
- TCP MBAP 匹配、RTU CRC16 校验、异常码解释、十六进制收发日志。
- TCP 服务器逐条处理耗时（0.2.2）：写请求最近/平均/峰值、成功与异常样本、筛选和 JSON 导出；[测量边界与操作说明](docs/TCP服务器处理耗时监测.md)。
- 写入前展示目标/地址/值，并使用 60 秒的一次性确认令牌；取消不会发送写入报文。
- 只读监视项、轮询、寄存器解码、TCP 客户端/服务器及 RTU 主站/从站收发日志，以及本机工作区导入导出（含本机数据集）。
- 客户端持续 FC16 写入“序号＋随机数”，FC03 写后读回及轮询比对；服务器本机自动变值可同时运行，提供统计、时长停止和 JSON 导出。
- [双角色连续读写操作指南](docs/双角色连续读写验证.md)：地址规划、软件配置、PLC 配合步骤、统计含义和后续现场验收。
- 0.2.3 自动记住上次参数与界面位置，关闭前保存最后变更；深色标题栏保留系统窗口按钮。[配置记忆说明](docs/配置自动记忆.md)。

## 本地开发

```powershell
npm ci
npm test
npm run dev
```

生产编译：

```powershell
npm run build
npm run package:win
```

`serialport` 已携带 Windows x64 的 N-API 预编译绑定；打包配置会直接复用该绑定，因此不需要安装完整 Visual Studio 或 C++ Build Tools。若未来升级依赖后该预编译绑定不再兼容，再单独评估是否需要工具链。

Windows 安装产物写入 `release/`；该目录与前端构建目录 `dist/` 分离，避免旧的 Electron 输出被重复打入安装包。

## 验收边界

自动化测试覆盖客户端/服务器与 RTU 协议编码、CRC、RTU 帧解析、TCP 服务器回读、RTU 从站分片请求、响应错配和写入确认。最终现场验收仍需一个已授权的 RTU 设备或虚拟串口对，确认真实 COM 口、接线、通信参数和允许写入范围。
