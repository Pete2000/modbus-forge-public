# 配置自动记忆（0.2.3）

安装并运行发布版本。首次使用时，未保存过的旧配置需要重新填写。

参数改完约400ms后自动保存，右上角显示“配置已自动记住”。正常关闭窗口前会再保存最后设置，改完立即关闭也会保留。下次打开同一Windows用户下的软件，自动恢复这些参数。

| 自动记住 | 内容 |
| --- | --- |
| 客户端通道 | 当前所选TCP/RTU类型、IP/端口/超时或串口参数 |
| 服务器通道 | TCP监听地址/端口、RTU串口参数、所选监听类型 |
| 单次请求 | 功能码、Unit ID、零基地址、数量、待写值文本 |
| 只读轮询 | 已添加项目的名称、请求及周期，重启后处于暂停状态 |
| 双角色测试 | 客户端读写及本机自动变值的全部配置参数 |
| 本机数据页 | Unit ID、数据区、起始地址、页大小、DEC/HEX进制 |
| 界面位置 | 当前模块、通道页、参数栏折叠、左右区域比例、解码方式 |

重启后客户端未连接、服务器未监听、轮询暂停、持续写入和本机自动变值未运行。按需手动启动，每次持续测试仍需确认。保存的写入值只是草稿，不会自动发送。

自动记忆只保存配置参数。需要保存本机寄存器/线圈数据时，仍点击“保存工作区”；需要可携带的配置及数据快照时点击“导出”。自动保存不会反复保存PLC写来的实时数据，也不会覆盖之前手动保存的数据快照。

默认工作区和自动配置保存在应用的Windows用户数据目录，版本升级继续使用同一目录。`workspace.json`保留手动数据快照，`preferences.json`保留最新参数。导入工作区后会保存为新的默认快照和参数；导入会停止当前通信及测试。

若参数暂时无效或磁盘写入失败，右上角显示“配置未保存”，悬停可查看原因。修正后会重新保存。关闭时仍保存失败会提供“返回修改”和“放弃未保存配置并退出”。已有文件损坏时不会自动用默认值覆盖，可通过“导入”载入有效工作区恢复。

顶部原浅色系统标题栏已改为36px深色可拖动区域；右侧仍使用系统的最小化、最大化/还原、关闭按钮。窗口边缘的系统缩放与系统级细边线仍由Windows管理。
