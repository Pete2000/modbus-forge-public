# 双角色连续读写验证

本工具支持 TCP 客户端持续读写与服务器数据区自动变值，可同时运行。只对已授权的设备和确认可用的寄存器操作。以下地址仅为示例，实际地址与数据解释请核对设备手册和现场配置。

## 地址规划

每个测试区只由一个来源写入；客户端测试的写入区、PLC 读取结果区与 PLC 写入区应互不重叠。确认每个寄存器的功能、零基地址、数量和设备支持的功能码。多寄存器测试需要两个连续的保持寄存器；注意不要覆盖运行中的数据或控制命令。

## 客户端持续读写

1. 在“TCP 客户端调试”连接目标服务器；确认 IP、端口和 Unit ID。
2. 在“双角色验证 → 客户端”填写经确认的起始地址、写入和读取间隔、写后等待、随机范围及运行时长。
3. 建议保留“差异或错误时停止”，点击“确认并开始持续写入”，核对目标与参数后确认。
4. 测试以功能码 16（十进制 16，十六进制 0x10）写入序号和随机值，再以功能码 03 读取并比对。观察写入、读取、一致、差异、错误和超时统计。

收到写入响应不等于读回一致；应结合写后读回结果判断。序号回绕和随机值重复的情况不能独立证明所有更新均被采集。

## TCP 服务器自动变值

1. 在“TCP 服务器模拟”选择 TCP 服务器，按本机网卡配置监听地址和端口，启动监听。默认 127.0.0.1:5020 仅用于本机，外部设备不能通过回环地址访问。
2. 在“双角色验证 → 服务器”填写 Unit ID、起始地址、变值间隔、随机范围与运行时长，确认后启动。
3. 在外部客户端使用功能码 03 读取对应两个保持寄存器，观察数值更新；外部写入请使用独立数据区。
4. 服务器统计是指定 Unit ID 收到的外部请求统计；它不证明 PLC 程序已经正确比对或执行控制。

## 停止与记录

同一连接上的请求串行处理；响应慢时周期可能延长，不补发积压周期。停止、断开连接或导入工作区会撤销后续操作；已经发送的写入无法撤回，通信中断后应检查设备实际状态。运行参数及统计可导出，保存的配置不会保存运行授权或自动重启测试。

验证实际设备时应记录时间、地址范围、周期、设备响应和异常情况。运行时长与验收标准由具体设备和使用环境决定。
