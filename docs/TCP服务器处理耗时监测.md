# TCP 服务器请求处理耗时

TCP 服务器对完整请求开始处理到本机响应发送回调的时间进行统计。界面显示最近、平均及峰值，右侧报文列表可查看单条记录。

1. 使用已确认的本机网卡地址和端口启动 TCP 服务器；默认 127.0.0.1:5020 只供本机访问。
2. 外部客户端按经授权且已确认的数据区、Unit ID 和地址发送请求。
3. 在服务器报文列表中查看请求、响应及处理耗时，可按角色、结果、地址或 IP 筛选。暂停可冻结列表和统计，恢复后显示当前缓冲区；清空会重置本窗口记录。
4. 可导出当前实时缓冲区中的报文。缓冲区最多保留 1000 条，旧条目移出后统计也会变化。

写请求摘要统计 TCP 服务器收到的功能码 05、06、0F、10 请求，包括异常样本。读请求可逐条显示处理耗时，但不计入写摘要；RTU 从站及电脑客户端记录不计入。筛选条件会影响摘要范围，缺少耗时字段的旧记录不会当作零处理。

该时间表示本机处理与发送回调等待，不包含设备轮询等待、完整帧到达前的等待、全部网络往返或界面刷新，也不能证明远端已经收到响应。要测量设备端完整往返，需要设备端计时或合适位置的抓包记录。显示小数位数不是测量精度的保证。
